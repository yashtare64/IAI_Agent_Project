# Simple Utility Agent

## Overview

Simple Utility Agent is a beginner-friendly Python program that provides four useful utilities through a menu-driven system.

The program can display the current date and time, perform basic calculations, check whether a number is even or odd, and convert temperature from Celsius to Fahrenheit.

## Features

- Display current date and time
- Perform basic arithmetic calculations
- Check whether a number is even or odd
- Convert Celsius to Fahrenheit
- Menu-driven interface
- Option to exit the program
